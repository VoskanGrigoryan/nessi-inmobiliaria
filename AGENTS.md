# Instrucciones del proyecto

## Principios de implementación

- Escribí la menor cantidad de código que resuelva bien el pedido.
- Elegí la solución más simple que sea legible y fácil de mantener.
- No agregues capas, abstracciones, componentes, utilidades, dependencias ni configuraciones sin una necesidad concreta.
- No implementes funcionalidades hipotéticas ni prepares el código para escenarios que todavía no existen.
- Reutilizá la estructura y las convenciones ya presentes; no reorganices archivos ajenos al pedido.
- Eliminá ejemplos, marcas, estilos y archivos de boilerplate que no use el proyecto.
- Evitá comentarios que repitan lo que el código ya deja claro.
- Mantené el diseño responsive y accesible sin agregar complejidad visual innecesaria.
- Usá Motion solo para animaciones sutiles con un propósito claro; preferí CSS para transiciones simples.
- No agregues ni ejecutes pruebas salvo que el usuario lo solicite.

## Cambios

- Antes de incorporar una dependencia, comprobá que el pedido o una necesidad concreta la justifique.
- Conservá los cambios existentes del usuario y limitá cada edición al alcance solicitado.
- Al terminar, resumí qué cambió y qué verificaciones ejecutaste.
